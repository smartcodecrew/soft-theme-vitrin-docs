# عروض ساخنة (Hot Deals)

دليل العميل لسكشن **عروض ساخنة**: تبويبات عروض متعددة مع عدّاد تنازلي، مصادر منتجات مرنة، سلايدر أو شبكة، وأدوات لرفع التفاعل.

| | |
|---|---|
| **الاسم في المحرر** | عروض ساخنة (Hot Deals) |
| **الاسم بالإنجليزية** | Hot Deals |
| **الملفات** | `sections/hot-deals.jinja` · `sections/hot-deals.schema.json` |
| **الاستخدام** | حملات العروض المحدودة زمنيًا وتقسيمها إلى تبويبات بحسب التصنيف أو الجمهور أو المدينة |

---

## 1) كيفية الإضافة

1. افتح **محرر الثيم** واضغط **إضافة قسم** → **عروض ساخنة (Hot Deals)**.
2. اختر **سلايدر** أو **شبكة**، ثم شكل التبويبات: كلاسيك أو ستوري.
3. اضبط العنوان والعدّاد التنازلي.
4. أضف تبويبًا واحدًا أو أكثر، وحدد مصدر المنتجات لكل تبويب.
5. راجع إعدادات التخطيط والحركة والألوان.

---

## 2) ترتيب الإعدادات في المحرر

### أ) طريقة عرض المنتجات وشكل التبويبات

- طريقة العرض: **سلايدر** أو **شبكة**.
- التبويبات: **كلاسيك** بشريط جانبي، أو **ستوري** بصور دائرية أفقية.
- رابط «عرض الكل» الخاص بالتبويب يظهر في النمط الكلاسيكي فقط.

### ب) المسافات العامة

مسافة علوية وسفلية من 0 إلى 80px، وخيار تمرير تبويبات الجوال أفقيًا مع Snap.

### ج) الخلفية والعنوان

- لون خلفية القسم.
- إظهار نمط خلفية؛ يمكن رفع صورة مخصصة، أو يظهر النمط الافتراضي عند عدم اختيار صورة.
- إظهار عنوان القسم، نصه ولونه.

### د) العدّاد التنازلي

| الإعداد | الشرح |
|---|---|
| نوع العدّاد | مدة متجددة بالساعات، أو تاريخ ووقت ثابت |
| عدد الساعات | يستخدم مع وضع المدة، والافتراضي 24 |
| تاريخ الانتهاء | بصيغة `YYYY-MM-DDTHH:mm:ss` |
| تسميات الوحدات | إظهار يوم/ساعة/دقيقة/ثانية |
| الألوان | نص العدّاد، خلفية المربعات، الأرقام، والفاصل |
| التنبيه | نبضة قرب النهاية واهتزاز في آخر 10 دقائق |

عند انتهاء العدّاد تظهر رسالة «العرض انتهى».

### هـ) التفاعل

يمكن إظهار عداد مشاهدات حيّة مع أقل وأعلى رقم ونص مخصص. الرقم المعروض محصور بين القيمتين المحددتين.

### و) التصنيفات / التبويبات (حتى 8)

لكل تبويب:

- عنوان، صورة موصى بها 80×80px، وبادج قصير.
- مصدر المنتجات: المتجر، تصنيف، أو اختيار يدوي.
- عدد المنتجات من 1 إلى 601، والافتراضي 48.
- ترتيب: افتراضي، الأحدث، الأكثر مبيعًا، الأعلى تقييمًا، لها خيارات، أعلى خصم، أو أقل سعر.
- عرض المخفضة فقط مع حد أدنى للخصم حتى 90%.
- تثبيت حتى 20 منتجًا في البداية.
- **صفقة اليوم** لتكبير أول منتج في وضع السلايدر فقط.
- رابط «عرض الكل» ونصه.
- الجمهور: الجميع أو الزوار أو العملاء المسجلون.
- تقييد حسب مدينة الشحن؛ افصل المدن بفاصلة.
- زر **أضف الكل للسلة** مع النص وألوان الخلفية والنص والأيقونة والإطار.

### ز) إعدادات السلايدر

- قوة Peek للجوال: حسب الإعداد، خفيف، متوسط، أو قوي.
- عدد البطاقات للجوال والتابلت واللابتوب والديسكتوب.
- مسافة مستقلة للجوال وسطح المكتب.
- أسهم مستقلة للجوال والديسكتوب وشريط تقدم اختياري.

### ح) إعدادات الشبكة

عدد الأعمدة للجوال الصغير والكبير والتابلت واللابتوب والديسكتوب، مع مسافات مستقلة للجوال وسطح المكتب.

### ط) الحركة

- ظهور تدريجي اختياري: صعود وتلاشي، تلاشي، تكبير، أو انزلاق.
- انتقال التبويبات: فوري، تلاشي، انزلاق، تكبير، أو ضبابية.
- تبديل تلقائي بين التبويبات كل 3 إلى 30 ثانية.

### ي) ألوان التبويبات

لون النص، لون النص النشط، خلفية التبويب النشط، ولون رابط «عرض الكل» في النمط الكلاسيكي.

---

## 3) سيناريوهات جاهزة

### A — تخفيضات نهاية اليوم

- سلايدر وتبويبات ستوري.
- عدّاد بتاريخ ثابت، مع التسميات والنبضة والاهتزاز.
- فعّل «المخفضة فقط» وحدًا أدنى 20%.
- رتّب حسب أعلى خصم.

### B — عروض حسب الأقسام

- تبويبات كلاسيك لكل تصنيف.
- مصدر كل تبويب: تصنيف.
- أضف رابط «عرض الكل» لكل تبويب.
- فعّل التبديل بتأثير تلاشي دون تدوير تلقائي.

### C — حملة مدينة محددة

- قيّد التبويب حسب مدن مثل `الرياض, جدة`.
- خصص تبويبًا للعملاء المسجلين.
- فعّل «أضف الكل للسلة» للحزمة المناسبة.

---

## ملاحظات مهمة

- يجب إضافة تبويب واحد على الأقل ليظهر محتوى المنتجات.
- مصادر المتجر والتصنيف تستطيع تحميل أكثر من الدفعة الأولية؛ التبويبات غير النشطة تُحمّل عند الحاجة.
- «صفقة اليوم» لا تعمل إلا في وضع السلايدر.
- «عرض الكل» متاح بصريًا مع التبويبات الكلاسيكية فقط.
- فلتر المدينة يعتمد على مدينة الشحن المختارة لدى العميل، لا على دولة المتجر.
