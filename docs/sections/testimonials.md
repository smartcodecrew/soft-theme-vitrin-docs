# آراء العملاء (Testimonials)

دليل العميل لسكشن **آراء العملاء**: يعرض آراء مضافة يدويًا، أو تقييمات منتجات تُجلب من زد، أو المصدرين معًا، ضمن سلايدر أو شبكة.

| | |
|---|---|
| **الاسم في المحرر** | آراء العملاء |
| **الاسم بالإنجليزية** | Testimonials |
| **الملفات** | `sections/testimonials.jinja` · `sections/testimonials.schema.json` |
| **الاستخدام** | بناء الثقة، إبراز تجارب العملاء، وربط التقييمات بالمنتجات |

---

## شكل السكشن على المتجر

كل بطاقة قد تحتوي على نجوم أو علامة اقتباس، عنوان للرأي، النص، اسم العميل، صورته أو الحرف الأول من اسمه، التاريخ، واسم المنتج المرتبط. يتغير المحتوى حسب مصدر التقييمات وخيارات البطاقة.

---

## 1) كيفية الإضافة

1. افتح **محرر الثيم** واختر الصفحة.
2. اضغط **إضافة قسم** → **آراء العملاء**.
3. اضبط عنوان القسم والعنوان الفرعي.
4. اختر مصدر التقييمات: يدوي، منتجات، أو كلاهما.
5. أضف الآراء اليدوية أو اختر المنتجات المطلوب جلب تقييماتها.
6. اختر شكل البطاقة وطريقة العرض.
7. اضبط الشبكة أو السلايدر والألوان.

---

## 2) مجموعات الإعدادات

### أ) العنوان

- إظهار أو إخفاء العنوان والعنوان الفرعي.
- لون مستقل لكل منهما.
- محاذاة إلى البداية أو الوسط.
- لا يظهر النص المفعّل إذا كان الحقل نفسه فارغًا.

### ب) مصدر التقييمات

| المصدر | النتيجة |
|---|---|
| يدوي فقط | يعرض قائمة الآراء التي تدخلها في المحرر |
| تقييمات المنتجات API | يجلب تقييمات المنتجات المختارة فقط |
| يدوي + تقييمات المنتجات | يبدأ بالآراء اليدوية ثم يضيف التقييمات المجلوبة |

عند استخدام تقييمات المنتجات يمكن ضبط:

- المنتجات المراد جلب تقييماتها.
- عدد التقييمات المطلوب من كل منتج: 1–24.
- أقل تقييم مسموح بعرضه: 1–5 نجوم.
- الحد الأقصى النهائي للعناصر المعروضة: 1–48.

### ج) الآراء اليدوية (حتى 24)

| الحقل | الاستخدام |
|---|---|
| اسم العميل | يظهر في بيانات صاحب الرأي |
| نص الرأي | المحتوى الأساسي للبطاقة |
| عنوان الرأي | عنوان اختياري أعلى النص |
| التقييم | من نجمة إلى 5 نجوم |
| التاريخ / ملاحظة | نص حر، مثل تاريخ الشراء أو «عميل موثّق» |
| صورة العميل | صورة اختيارية؛ عند غيابها يظهر الحرف الأول |
| اسم المنتج المرتبط | يظهر أسفل بيانات العميل عند تفعيل عرضه |
| رابط المنتج | يجعل اسم المنتج قابلًا للنقر |

### د) بطاقة الرأي

- الأيقونة: نجوم، علامة اقتباس، الاثنان، أو بدون.
- إظهار صورة/حرف العميل.
- إظهار التاريخ.
- إظهار اسم المنتج المرتبط.

### هـ) التخطيط

- طريقة العرض: سلايدر أو شبكة.
- المسافة بين البطاقات للويب والموبايل.
- المسافة العلوية والسفلية.
- استدارة البطاقة من 0 إلى 24 بكسل.
- عرض كامل الحافة.

### و) الشبكة والسلايدر

في الشبكة: حتى 4 أعمدة للديسكتوب، 3 للتابلت، و2 للموبايل.

في السلايدر: عدد الشرائح للديسكتوب والتابلت والموبايل، وإظهار الأسهم أو النقاط، والتكرار، والتشغيل التلقائي من 2000 إلى 10000 مللي ثانية.

### ز) الألوان

تشمل خلفية القسم والبطاقة وحدودها، ونص الرأي، واسم العميل، والنص الثانوي، والنجوم، وعلامة الاقتباس. ألوان العنوان والعنوان الفرعي موجودة ضمن مجموعة العنوان.

---

## 3) الشروط والسلوك الفعلي

- الرأي اليدوي لا يُضاف إلى العرض إلا إذا احتوى على اسم أو نص.
- في وضع **المنتجات فقط** تُزال العناصر اليدوية ويُعرض الناتج القادم من API.
- في وضع **كلاهما** تُدمج الآراء اليدوية مع تقييمات المنتجات.
- تقييمات API التي لا تحتوي على نص تُستبعد، وكذلك ما يقل عن الحد الأدنى للنجوم.
- يطبق الحد الأقصى بعد جمع تقييمات المنتجات المختارة.
- عند عدم اختيار منتجات في وضع API تظهر رسالة تطلب اختيار منتجات.
- قد تظهر رسائل تحميل أو عدم وجود تقييمات أو تعذر الجلب حسب نتيجة الاتصال.
- جلب التقييمات يتم في واجهة المتجر عبر `zid.products.reviews` مع دعم واجهة أقدم عند توفرها.
- التاريخ القادم من API يعرض كما ترسله المنصة؛ لا يوجد تنسيق تاريخ يدوي داخل السكشن.
- اسم المنتج القادم من API يُربط تلقائيًا بصفحة المنتج.

---

## 4) سيناريوهات جاهزة

### A — آراء تسويقية منتقاة

- المصدر: يدوي فقط.
- أضف 4–8 آراء قصيرة بصور اختيارية.
- اختر النجوم مع الاقتباس.
- استخدم سلايدر بثلاث بطاقات على الديسكتوب.

### B — تقييمات فعلية لمنتجات محددة

- المصدر: تقييمات المنتجات.
- اختر المنتجات الأكثر مبيعًا.
- اجعل أقل تقييم 4 نجوم.
- حدد 6 تقييمات لكل منتج و12 عنصرًا كحد أقصى.

### C — مزيج اجتماعي وفعلي

- المصدر: يدوي + تقييمات المنتجات.
- أضف رأيين بارزين يدويًا.
- اختر عدة منتجات لجلب التقييمات الحديثة.
- فعّل اسم المنتج والتاريخ لزيادة الوضوح.

### D — صفحة هادئة بلا حركة

- اختر الشبكة.
- استخدم عمودًا واحدًا على الجوال وثلاثة على الديسكتوب.
- عطّل عناصر البطاقة غير الضرورية لتقليل الزحام.

## ملاحظات مهمة

- تقييمات المنتجات تعتمد على توفر API وعلى وجود تقييمات نصية للمنتجات المختارة.
- `عدد التقييمات لكل منتج` ليس هو الحد النهائي؛ استخدم `الحد الأقصى` لضبط إجمالي المعروض.
- في وضع «كلاهما» قد يتجاوز العدد الإجمالي الحد المحدد لأن الحد يطبق على عناصر API، بينما تبقى الآراء اليدوية مضافة.
- إذا لم تظهر النجوم، راجع خيار أيقونة البطاقة لا قيمة التقييم فقط.
- أدخل رابط المنتج مع اسمه؛ الرابط وحده لا يعرض عنصرًا مرئيًا.
