# أعمدة الخصائص (Icon columns)

دليل العميل لسكشن **أعمدة الخصائص**: أعمدة مختصرة بأيقونات وعناوين وأوصاف لعرض مزايا الخدمة، مثل الدفع الآمن والتوصيل وضمان الجودة.

| | |
|---|---|
| **الاسم في المحرر** | أعمدة الخصائص |
| **الاسم بالإنجليزية** | Features columns |
| **الملفات** | `sections/icon-columns.jinja` · `sections/icon-columns.schema.json` |
| **الاستخدام** | بناء شريط ثقة أو قائمة مزايا وخدمات قابلة للتخصيص والاستهداف |

---

## 1) كيفية الإضافة

1. افتح **محرر الثيم** في زد واختر الصفحة.
2. اضغط **إضافة قسم** → **أعمدة الخصائص**.
3. اختر نمط العنصر: أيقونة فوق النص أو بجانبه.
4. أضف الأعمدة، واختر أيقونة وعنوانًا ووصفًا لكل عمود.
5. اضبط عدد الأعمدة والألوان والحركة.

> الحد الأقصى 8 أعمدة. غالبًا تكفي 3 أو 4 مزايا حتى تبقى الرسالة سريعة وواضحة.

---

## 2) ترتيب الإعدادات في المحرر

### أ) التخطيط

| الإعداد | الشرح |
|---|---|
| نمط عرض العنصر | **أيقونة فوق النص** لتخطيط عمودي، أو **أيقونة جنب النص** لتخطيط أفقي |
| أعمدة سطح المكتب | من عمودين إلى 6 أعمدة |
| أعمدة الجوال | من عمود إلى 3 أعمدة |
| الفواصل العمودية | تضيف فواصل بصرية بين العناصر |
| محاذاة النص | بداية، وسط، أو نهاية |
| اتجاه القسم | تلقائي حسب اللغة، RTL، أو LTR |
| عرض الشاشة بالكامل | يمد الشبكة إلى كامل العرض |
| حجم الأيقونة | قيمة مستقلة للويب والموبايل |
| المسافة بين العناصر | قيمة مستقلة للويب والموبايل |
| المسافات العلوية والسفلية | قيم مستقلة للويب والموبايل |

### ب) الأعمدة

لكل عمود الإعدادات التالية:

| الإعداد | ماذا يفعل؟ |
|---|---|
| أيقونة جاهزة | دفع آمن، دردشة وتنبيهات، ضمان الجودة، أو توصيل |
| صورة مخصصة | يظهر حقل رفع صورة بدل الأيقونات الجاهزة |
| العنوان | اسم الميزة |
| الوصف | شرح قصير للميزة |
| تفعيل الرابط | يحول العمود كاملًا إلى رابط عند وجود وجهة |
| فتح في تبويب جديد | يظهر عند تفعيل الرابط، ويضيف فتحًا آمنًا في تبويب منفصل |
| من يرى العمود؟ | الجميع، الزوار فقط، أو العملاء المسجلون |
| تقييد حسب الدولة | يعرض العمود للدول المحددة فقط |
| أسماء الدول المسموحة | قائمة أسماء مفصولة بفاصلة؛ تدعم أيضًا اسم المدينة إن توفر |

إذا كان العمود فارغًا تمامًا من الأيقونة والعنوان والوصف فلن يظهر.

### ج) الألوان

- لون الأيقونة الجاهزة.
- لون العنوان.
- لون الوصف.
- لون الفاصل عند تفعيل الفواصل.
- خلفية السكشن، ويمكن تركها شفافة.

> لون الأيقونة يطبق على الرسومات الجاهزة. الصورة المرفوعة تحتفظ بألوانها الأصلية.

### د) الحركة

| الإعداد | الخيارات |
|---|---|
| تفعيل حركة الأيقونات والصور | تشغيل أو إيقاف الحركة |
| نوع الحركة | طفو، نبض، ارتداد، اهتزاز، تكبير عند المرور، أو رفع عند المرور |
| ظهور تدريجي عند التمرير | يكشف الأعمدة تدريجيًا عند وصول الزائر إليها |

## 3) الاستهداف حسب الجمهور والموقع

يمكن تخصيص كل عمود بشكل مستقل:

- **الزوار فقط:** مناسب لميزة إنشاء الحساب أو أول طلب.
- **المسجلون فقط:** مناسب لنقاط الولاء أو مزايا الأعضاء.
- **الجميع:** لا يطبق فلتر تسجيل الدخول.
- **حسب الدولة:** يقارن الاسم بالدولة المختارة في نافذة الشحن.

اكتب أكثر من اسم بفاصلة، مثل: `مصر, السعودية`. يقبل القالب الفاصلة العربية `،` أيضًا، ويطبع الأسماء العربية لتسهيل المطابقة.

## 4) سيناريوهات جاهزة

### A — شريط ثقة أسفل الهيدر

- 4 أعمدة على الديسكتوب وعمودان على الجوال.
- أيقونة فوق النص.
- فعّل الفواصل العمودية.
- استخدم عناوين: دفع آمن، توصيل سريع، جودة مضمونة، ودعم مستمر.

### B — روابط خدمات

- فعّل الرابط لكل عمود.
- اربط التوصيل بسياسة الشحن، والدفع بصفحة طرق الدفع.
- استخدم **أيقونة جنب النص** ومحاذاة البداية.

### C — مزايا محلية

- كرر عمود التوصيل بإعدادات مختلفة لكل دولة.
- فعّل تقييد الدولة واكتب أسماء الدول كما تظهر في نافذة الشحن.
- استخدم عنوانًا يوضح مدة التوصيل الخاصة بكل سوق.

---

## ملاحظات مهمة

- لا يكفي تفعيل الرابط وحده؛ يجب إدخال رابط صالح حتى تصبح البطاقة قابلة للنقر.
- إعداد **فتح في تبويب جديد** لا يعمل إلا مع رابط مفعّل ومكتمل.
- فلتر الدولة يعتمد على الدولة المختارة للشحن، وقد يقبل المدينة أيضًا إذا كانت بياناتها متاحة.
- إذا اختفت كل الأعمدة بسبب الجمهور أو الموقع، لا يعرض القالب السكشن.
- تجنب الحركة المستمرة القوية عند استخدام عدد كبير من الأعمدة.
