# تابات شبكية (Tabs Grid)

دليل العميل لسكشن **تابات شبكية**: مجموعات منتجات داخل تبويبات مصورة، مع صورة أو فيديو مميز لكل تبويب وسلايدر أو شبكة للمنتجات.

| | |
|---|---|
| **الاسم في المحرر** | تابات شبكية |
| **الاسم بالإنجليزية** | Tabs Grid |
| **الملفات** | `sections/fresh-picks.jinja` · `sections/fresh-picks.schema.json` |
| **الاستخدام** | عرض مجموعات متعددة في مساحة واحدة، وربط كل مجموعة بوسائط ترويجية ومنتجات خاصة |

---

## 1) كيفية الإضافة

1. افتح **محرر الثيم** واضغط **إضافة قسم** → **تابات شبكية**.
2. اختر طريقة عرض المنتجات: سلايدر أو شبكة.
3. أضف التبويبات، وحدد مصدر منتجات كل تبويب.
4. أضف صورة أو فيديو مميزًا لكل تبويب عند الحاجة.
5. اضبط عنوان القسم والتخطيط والسلايدر أو الشبكة والألوان.

> لا يظهر السكشن في الواجهة إذا لم توجد تبويبات متاحة للجمهور الحالي.

---

## 2) ترتيب الإعدادات في المحرر

### أ) طريقة عرض المنتجات

تحدد إظهار إعدادات **السلايدر** أو **الشبكة** لاحقًا في المحرر.

### ب) التبويبات (حتى 20)

#### بيانات ومصدر المنتجات

- عنوان التبويب وصورته؛ المقاس الموصى به للصورة 72×72px.
- المصدر: جميع منتجات المتجر، تصنيف، أو اختيار يدوي.
- عدد المنتجات من 1 إلى 601، والافتراضي 24.
- الترتيب: افتراضي، الأحدث، الأكثر مبيعًا، الأعلى تقييمًا، أو منتجات لها خيارات.

#### الوسائط المميزة

| الإعداد | التفاصيل |
|---|---|
| إظهار الوسائط | تفعيل أو إخفاء المساحة الترويجية |
| النوع | صورة/بانر أو فيديو |
| الصورة | المقاس الموصى به 560×1070px |
| الفيديو | ملف MP4 حتى 10MB |
| غلاف الفيديو | اختياري ويظهر قبل التشغيل |
| التشغيل | تلقائي صامت مع زر تشغيل/إيقاف اختياري |
| المحتوى | عنوان، زر اختياري، رابط، وألوان للعنوان والزر |

إذا كان رابط الوسائط فارغًا، يستخدم السكشن رابط «عرض الكل»، ثم `/products` كوجهة احتياطية.

#### عرض الكل والظهور

- رابط «عرض الكل» ونصه مستقلان لكل تبويب.
- الجمهور: الجميع، الزوار فقط، أو العملاء المسجلون.
- تقييد حسب مدينة الشحن؛ افصل أسماء المدن بفاصلة مثل `الرياض, جدة`.

### ج) العنوان

عنوان القسم ولونه، ولون زر «عرض الكل» المتغير بحسب التبويب النشط.

### د) التخطيط والعرض

- اتجاه تلقائي أو RTL أو LTR.
- عرض البانر على الديسكتوب من 200 إلى 400px.
- المسافة بين البانر والمنتجات من 0 إلى 24px.
- عرض الشاشة بالكامل.
- مسافات علوية وسفلية مستقلة للجوال والديسكتوب.

### هـ) إعدادات السلايدر

- Peek للجوال: يدوي أو خفيف أو متوسط أو قوي.
- عدد المنتجات الظاهرة لكل مقاس، مع دعم نصف بطاقة.
- مسافات مستقلة للجوال والديسكتوب.
- أسهم مستقلة، نقاط، تشغيل تلقائي من 2000 إلى 8000 مللي ثانية، وتكرار لا نهائي.

### و) إعدادات الشبكة

أعمدة مستقلة للجوال الصغير والكبير والتابلت واللابتوب والديسكتوب، ومسافات مستقلة للجوال والديسكتوب. الافتراضي على الديسكتوب 4 أعمدة.

### ز) الألوان والاستدارة

ألوان نص التبويب العادي والنشط وخلفية التبويب النشط، واستدارة الوسائط المميزة من 0 إلى 24px.

---

## 3) سيناريوهات جاهزة

### A — أقسام متجر الأغذية

- تبويب للحوم وآخر للخضار وآخر للمخبوزات.
- مصدر كل تبويب: تصنيف.
- صورة بانر عمودية وعنوان وزر لكل تبويب.
- سلايدر مع Peek متوسط على الجوال.

### B — حملات فيديو

- اختر فيديو مميزًا قصيرًا لكل تبويب.
- فعّل التشغيل التلقائي الصامت وزر التشغيل/الإيقاف.
- استخدم غلاف فيديو واضحًا.
- اجعل عرض البانر 280px مع شبكة 4 أعمدة.

### C — محتوى محلي للعملاء

- أنشئ تبويبات بعروض مختلفة حسب مدينة الشحن.
- اجعل بعضها للعملاء المسجلين فقط.
- استخدم رابط «عرض الكل» منفصلًا لكل مدينة أو مجموعة.

---

## ملاحظات مهمة

- الوسائط لا تظهر إلا عند توفير صورة أو فيديو فعلي حتى لو كان خيار الإظهار مفعّلًا.
- الفيديو يعمل داخل بانر متكرر وصامت، ويحتاج MP4 خفيفًا لأداء جيد.
- مصادر المتجر والتصنيف تحمّل المزيد عند تجاوز المنتجات المتاحة أوليًا.
- التبويبات التي لا تطابق الجمهور أو مدينة الشحن تُستبعد قبل العرض.
