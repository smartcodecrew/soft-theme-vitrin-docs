## 1) كيفية الإضافة

1. افتح **محرر الثيم** في زد.
2. اختر الصفحة المطلوبة.
3. اضغط **إضافة قسم** → **شعارات الثقة**.
4. ارفع الشعارات، ثم اختر نمط العرض (سلايدر أو شبكة).

> الحجم الموصى به لكل شعار: ارتفاع حوالي **65px** وعرض تلقائي.

---

## 2) ترتيب الإعدادات في المحرر

### أ) الشعارات (حتى 20)

| الإعداد | الشرط | الشرح |
|---------|--------|--------|
| الصورة | — | ملف الشعار / الشارة |
| شكل الصورة | — | Contain (موصى به) أو Cover |
| تفعيل الرابط | — | يجعل الشعار قابلاً للنقر |
| الرابط | الرابط مفعّل | وجهة النقر |
| عرض مخصص | مفعّل | يفعّل ضبط العرض بالبكسل |
| عرض الشعار (px) | عرض مخصص | من 48 إلى 200 |
| تقييد حسب الدولة | مفعّل | يظهر الشعار لدول محددة فقط |
| أسماء الدول | التقييد مفعّل | مفصولة بفاصلة |

### ب) نمط العرض

| القيمة | المعنى |
|--------|--------|
| سلايدر / تمرير أفقي | صف واحد يتحرك (Marquee) |
| شبكة (Grid) | ترتيب ثابت بأعمدة حسب الشاشة |

### ج) الحركة (تظهر مع السلايدر فقط)

| الإعداد | الشرح |
|---------|--------|
| عرض كامل للشاشة | يمتد لعرض الصفحة بدل الكونتينر |
| تفعيل التمرير التلقائي | تشغيل/إيقاف الحركة |
| اتجاه الحركة | بداية ↔ نهاية |
| نوع الحركة | مستمر / ناعم / خطوات / ذهاب وعودة |
| سرعة الحركة (ثواني) | مدة دورة التمرير |
| إيقاف عند التمرير بالماوس | Pause on hover |
| تكرار الشعارات في المسار | يكرر القائمة لملء الشريط |

### د) إعدادات الشبكة (تظهر مع الشبكة فقط)

أعمدة لكل مقاس شاشة (جوال صغير → سطح المكتب) + محاذاة الشبكة (بداية / وسط / نهاية).

### هـ) التخطيط والألوان

| الإعداد | الشرح |
|---------|--------|
| ارتفاع الشعار (px) | ارتفاع موحّد للصور |
| المسافة بين الشعارات | جوال / سطح المكتب |
| انحناء زوايا الشعار | Border radius |
| المسافات (Padding) | أعلى/أسفل للجوال والويب |
| لون الخلفية | خلفية القسم |

## 3) سيناريوهات جاهزة

### سيناريو A — شريط شهادات متحرك تحت الهيرو

1. نمط العرض: **سلايدر / تمرير أفقي**  
2. فعّل التمرير التلقائي + إيقاف عند الماوس  
3. ارفع 5–10 شعارات بخلفية شفافة إن أمكن  

### سيناريو B — شبكة ثابتة في فوتر الصفحة

1. نمط العرض: **شبكة**  
2. اضبط الأعمدة (مثل 4 تابلت / 7 سطح مكتب)  
3. عطّل الروابط إن كانت للعرض فقط  

### سيناريو C — شعار بحجم مختلف

1. فعّل **عرض مخصص** على شعار واحد (مثل Halal)  
2. اضبط العرض ليبرز وسط الباقي  

---

## 4) ملاحظات مهمة

1. استخدم صور **PNG شفافة** لنتائج أنظف على أي خلفية.  
2. Contain يحافظ على نسبة الشعار؛ Cover قد يقص الحواف.  
3. في وضع السلايدر المتحرك، تكرار الشعارات في المسار طبيعي لعمل اللوب.  
4. فلتر الدولة يعتمد على دولة جلسة الزائر في زد.
