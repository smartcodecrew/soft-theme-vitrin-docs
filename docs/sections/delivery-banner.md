# بانر التوصيل (Delivery banner)

دليل العميل لسكشن **بانر التوصيل**: بانر واسع يجمع عنوانًا بنص مميز، وصفًا، قائمة مزايا بأيقونات، وصورة جانبية اختيارية.

| | |
|---|---|
| **الاسم في المحرر** | بانر التوصيل |
| **الاسم بالإنجليزية** | Delivery banner |
| **الملفات** | `sections/delivery-banner.jinja` · `sections/delivery-banner.schema.json` |
| **الاستخدام** | شرح التوصيل أو ضمانات المتجر أو نقاط الثقة في كتلة واحدة |

---

## شكل السكشن على المتجر

يتكون من مساحة محتوى فيها عنوان ووصف وحتى 6 ميزات، وبجانبها صورة اختيارية. جزء من العنوان يمكن تمييزه بلون وحركة، ويمكن عكس موضع الصورة واتجاه السكشن.

## 1) كيفية الإضافة

1. افتح **محرر الثيم** في زد.
2. اختر الصفحة ثم **إضافة قسم** → **بانر التوصيل**.
3. قسّم العنوان إلى نص قبل التمييز، ونص مميز، ونص بعده.
4. أضف وصفًا ثم ميزات التوصيل أو الثقة.
5. ارفع الصورة واضبط موضعها وعرضها.
6. اضبط الألوان والظهور، ثم اختبر العربية والإنجليزية والجوال.

> اجعل نص التمييز قصيرًا، مثل «في نفس اليوم»، حتى تبقى الحركة واضحة ولا تشتت العنوان.

## 2) ترتيب الإعدادات في المحرر

### أ) المحتوى

العنوان مكوّن من ثلاثة حقول متتابعة:

1. العنوان قبل التمييز.
2. نص التمييز.
3. العنوان بعد التمييز.

يمكن ضبط محاذاة النصوص إلى البداية أو الوسط أو النهاية.

عند تفعيل **إظهار الوصف** يظهر حقل الوصف في المحرر. وفي المتجر لا يُعرض إلا إذا كان الخيار مفعّلًا وكان النص غير فارغ.

### ب) التمييز

| الإعداد | الشرح |
|---|---|
| لون التمييز | اللون الخاص بجزء العنوان الأوسط |
| أنيميشن تغيير اللون | يفعّل ظهور تأثير اللون |
| تأخير الأنيميشن | من 0 إلى 2000ms ويظهر فقط عند تفعيل الحركة |

إذا عطلت الحركة، يبقى النص المميز ملونًا مباشرة دون انتظار.

### ج) الصورة

- الصورة اختيارية؛ عند غيابها يتم عرض المحتوى بدون عمود وسائط.
- رابط الصورة اختياري ويجعل الصورة قابلة للنقر.
- إذا أضفت رابطًا بلا صورة فلن يظهر رابط مستقل.
- النص البديل للصورة يُبنى من أجزاء العنوان الثلاثة.

### د) التخطيط

| الإعداد | ماذا يفعل؟ |
|---|---|
| اتجاه القسم | تلقائي حسب لغة المتجر، أو RTL، أو LTR |
| موضع الصورة | البداية أو النهاية |
| عرض الصورة | من 20% إلى 50% على الديسكتوب |
| استدارة الصورة | من 0 إلى 24px |
| حجم الأيقونة | قيمة مستقلة للويب والموبايل |
| استدارة السكشن | من 0 إلى 24px على الويب |
| المسافات | أعلى وأسفل بصورة مستقلة للويب والموبايل |
| عرض الشاشة بالكامل | يمد البانر بدل تقييده داخل الحاوية |

خيار **تلقائي** يستخدم اتجاه لغة المتجر: العربية RTL واللغات اليسارية LTR. موضع «البداية» و«النهاية» يتفاعل مع هذا الاتجاه، لذلك اختبر النتيجة بعد تغيير اللغة.

### هـ) الألوان

تتوفر ألوان مستقلة لخلفية البانر، والعنوان، والوصف، وعنوان الميزة، ووصف الميزة، إضافة إلى لون التمييز.

### و) الميزات (حتى 6)

لكل ميزة:

- أيقونة جاهزة: جودة، رضا، أو جائزة.
- أو اختيار **مخصص** ثم رفع صورة أيقونة.
- عنوان ووصف.

عند اختيار أيقونة جاهزة يستخدم السكشن ملفات الأيقونات الموجودة في الثيم. حقل **الأيقونة المخصصة** يظهر فقط عند اختيار «مخصص». وإذا كانت صورة مخصصة محفوظة، يعطيها القالب الأولوية عند العرض.

### ز) الظهور والجمهور

شرط الظهور يطبق على **السكشن كاملًا**:

- الجميع.
- الزوار غير المسجلين فقط.
- العملاء المسجلون فقط.
- تقييد اختياري حسب الدولة.

عند تفعيل تقييد الدولة يظهر حقل الدول المسموحة. يعتمد القالب على دولة الجلسة ووجهة الشحن المختارة، ويقبل الاسم العربي أو الإنجليزي أو رمز الدولة. افصل القيم بفاصلة مثل `مصر, السعودية`.

إذا لم تتطابق حالة العميل أو الدولة، لا يُطبع السكشن نهائيًا. وإذا فعّلت الفلتر وتركت الحقل فارغًا، لا يفرض القالب منعًا؛ أضف دولة واحدة على الأقل.

### ح) ملخص `visible_if`

| الشرط | النتيجة في المحرر |
|---|---|
| إظهار الوصف = مفعّل | يظهر حقل الوصف |
| أنيميشن التمييز = مفعّل | يظهر تأخير الأنيميشن |
| تقييد الدولة = مفعّل | يظهر حقل الدول |
| الأيقونة الجاهزة = مخصص | يظهر رفع الأيقونة المخصصة |

أسماء شروط حقول الـ fieldset مكتوبة بالصيغة المجمعة مثل `content_show_description` و`visibility_enable_geo_filter`، وهي متوافقة مع طريقة قراءة القالب للإعدادات.

## 3) سيناريوهات جاهزة

### A — وعد التوصيل

- العنوان قبل التمييز: «توصيل طلبك».
- نص التمييز: «في نفس اليوم».
- 3 ميزات: تغطية المناطق، حفظ المنتجات، ودعم الطلب.
- صورة سيارة توصيل برابط صفحة سياسة الشحن.

### B — شريط ثقة بدون صورة

- اترك الصورة فارغة.
- أضف 4 إلى 6 ميزات بأيقونات جاهزة.
- وسّط النصوص واستخدم خلفية بلون الهوية.
- عطّل حركة التمييز إذا كانت الصفحة تحتوي حركات كثيرة.

### C — رسالة شحن حسب الدولة

- أنشئ نسخة للسعودية وأخرى لمصر.
- قيد كل سكشن بالدولة المناسبة.
- غيّر النص والصورة والميزات حسب زمن وأسعار التوصيل المحلية.

## ملاحظات مهمة

- إذا لم يظهر السكشن، راجع الجمهور والدولة قبل مراجعة المحتوى.
- الرابط يخص الصورة فقط؛ العنوان والميزات ليست روابط.
- لا تظهر مساحة الصورة إذا لم تُرفع صورة، حتى لو ضُبط عرضها.
- استخدم أيقونات متقاربة بصريًا، خصوصًا عند خلط الجاهز بالمخصص.
- راقب التباين بين ألوان النص والخلفية، فالبانر يجمع عدة مستويات نصية.
