# دليل أقسام الثيم (Sections)

**الواجهة الرئيسية للعملاء:** صفحة واحدة بأسلوب تسويقي تعرض كل الأقسام مع معاينات وشرح الإعدادات:

→ **[افتح الدليل (صفحة واحدة)](../index.html)**

> الهدف النهائي: صفحة مشابهة لصفحات الثيمات التسويقية (مثل [ثيم سيليا](https://selia-tech.com/selia-theme/)) — هيرو + خريطة أقسام + شرح كل سكشن بصور وسيناريوهات — كلها في مكان واحد.

## الأقسام المتوفرة (تفصيلي Markdown)

| السكشن | الملف | الدليل |
|--------|------|--------|
| قائمة التصنيفات | `collection-grid` | [شرح كامل + صور](./collection-grid.md) · [في الصفحة الواحدة](../index.html#collection-grid) |

> بقية الأقسام ظاهرة في خريطة [الصفحة الواحدة](../index.html#sections) وستُضاف تدريجيًا بنفس الأسلوب.

## كيف تضيف أي سكشن؟

1. من لوحة تحكم **زد** افتح المتجر → **التصميم** → **محرر الثيم**.
2. افتح الصفحة المطلوبة (مثل الصفحة الرئيسية).
3. اضغط **إضافة قسم / Add section**.
4. اختر اسم السكشن من القائمة.
5. اضبط الإعدادات حسب الدليل، ثم **حفظ**.
