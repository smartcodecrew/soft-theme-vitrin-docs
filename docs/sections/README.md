# دليل أقسام الثيم (Sections)

شرح مخصص للعملاء: كيفية إضافة كل سكشن وضبط إعداداته من محرر ثيم زد.

## الأقسام المتوفرة

| السكشن | الملف | الدليل |
|--------|------|--------|
| قائمة التصنيفات | `collection-grid` | [شرح كامل + صور](./collection-grid.md) |

> سيتم إضافة بقية الأقسام هنا تدريجيًا بنفس الأسلوب.

## كيف تضيف أي سكشن؟

1. من لوحة تحكم **زد** افتح المتجر → **التصميم** → **محرر الثيم**.
2. افتح الصفحة المطلوبة (مثل الصفحة الرئيسية).
3. اضغط **إضافة قسم / Add section**.
4. اختر اسم السكشن من القائمة.
5. اضبط الإعدادات حسب الدليل الخاص به، ثم **حفظ**.
